# ADR-0043: Стандарт 1:1 Liquid Glass Popover для клиентских xdg_popup поверхностей и декомпозиция рендера меню в rusty-files

- **Статус:** accepted
- **Дата:** 2026-11-17
- **Задача:** `RUSTYOS-087`
- **Связанные решения:** `D-051`, `D-050`, `D-038`, `ADR-0042`, `ADR-0030`

## Контекст

1. **Визуальный рассинхрон контекстных меню:**
   В ходе живого тестирования в сессии `--winit` выявлено грубое визуальное расхождение:
   - Контекстные меню рабочего стола, Дока и окон в композиторе отрисовываются на GPU с эффектом **Liquid Glass**: скругление 16px, акриловая полупрозрачность, зеркальный верхний ободок (`rgba(255, 255, 255, 45)`), плавающие инсетные пилюли ховера 8px с отступом 6px, глубокая гауссова тень и колонка шорткатов.
   - В то же время контекстные и выпадающие меню в `rusty-files` (и других Wayland-приложениях) отрисовывались встроенным CPU-растеризатором в буфер поверхности `xdg_popup` как плоские непрозрачные плашки с радиусом 12px, грубой прямоугольной синей заливкой ховера от края до края без инсетов, ступенчатой 3-слойной тенью и без колонки горячих клавиш.
   - Это прямо нарушало [DESIGN.md](file:///home/anc/RustyOS_Main/DESIGN.md#L333-L350) §10 (*«Every RustyOS component must feel like part of one operating system»*) и референсы macOS 27 Golden Gate (`finder/27-Golden-Gate-Finder-Menu.png`).

2. **Монолитный файл рендерера:**
   `apps/rusty-files/src/render.rs` разросся до 2614 строк, совмещая низкоуровневые примитивы 2D Canvas, типографику, сайдбар, тулбар, 4 режима отображения файлов и логику всплывающих меню.

## Решение

1. **Спецификация 1:1 Liquid Glass Popover для поверхностей `xdg_popup`:**
   - **Геометрия панели:** скругление `MENU_POPOVER_RADIUS = 16px` (полное совпадение с композитором);
   - **Подложка Liquid Glass:** полупрозрачная тонированная основа (`rgba(246, 248, 252, 242)` для Light Golden Gate, `rgba(32, 34, 38, 242)` для Dark Purple Glass) с верхним зеркальным кантом `rgba(255, 255, 255, 80)` / `rgba(255, 255, 255, 38)` и тонкой рамкой;
   - **Многостадийная мягкая тень:** 6-слойная гауссова SDF-тень с вертикальным смещением вниз (+2..4px) и радиусами размытия 16..21px;
   - **Плавающая инсетная пилюля ховера:** скругление `HOVER_PILL_RADIUS = 8px`, горизонтальный инсет `HOVER_PILL_INSET_H = 6px`, вертикальный инсет `HOVER_PILL_INSET_V = 1px`, заливка цветом системного акцента `pal.accent` (`#007AFF` / `#0A84FF`) с белым текстом;
   - **Колонка горячих клавиш:** правое выравнивание шорткатов (`⇧⌘N`, `⌘T`, `Space`, `⌘I`, `⏎`, `⌘C`, `⌘X`, `⌘V`, `⌘D`, `⌘⌫`, `^⌘F`, `⌘M`, `⌘W`, `⇧⌘.`) вторичным цветом текста;
   - **Тонкие разделители секций:** hairline-линии с отступом 12px от краев;
   - **Деструктивные действия:** цветовое выделение `popover_danger` (`#D7303E` / `#FF6961`) для «Move to Trash» и «Empty Trash».

2. **Декомпозиция рендера меню (`apps/rusty-files/src/render/popup.rs`):**
   - Вынос отрисовки popover/context меню из монолитного `render.rs` в изолированный модуль `apps/rusty-files/src/render/popup.rs`;
   - Реэкспорт `render_popup` и `render_popup_surface_pixels` для полной обратной совместимости;
   - Добавление токенов `popover_bg`, `popover_border`, `popover_rim`, `popover_text_primary`, `popover_text_secondary`, `popover_text_muted`, `popover_danger`, `popover_separator` в `Palette`.

3. **Обновление геометрии раскладки (`apps/rusty-files/src/layout.rs`):**
   - Расширение ширины контекстных и экшен-меню до 230px для комфортного размещения длинных меток и шорткатов без наложений.

## Последствия

- **Визуальная целостность:** контекстные меню и выпадающие списки внутри `rusty-files` стали визуально неотличимы от системных контекстных меню композитора (рабочий стол, Док, заголовки окон).
- **Чистота архитектуры:** `render.rs` разгружен; логика попапов изолирована и покрыта unit-тестами.
- **Совместимость:** сохранена автономность клиентского приложения через стандартный протокол `xdg_popup`.
