# ADR-0051: CutefishOS Calibrated Dock Glass and Drop Shadow Removal

## Status

accepted

## Context

Пользователь указал на расхождения живого Дока с эталоном CutefishOS:
1. В коде композитора присутствовали искусственные диагональные угловые 3D-блики (`arc_tl` в верхнем левом углу и `arc_br` в нижнем правом), а также градиентная вертикальная дымка (`sheen`), из-за чего контейнер Дока визуально казался пластиковой выпуклой кнопкой.
2. Под контейнером Дока принудительно рисовалась внешняя темная рассеянная тень (`push_soft_shadow(..., 20, 72)`), которой нет на референсе CutefishOS.

Исследование официального репозитория `cutefishos/cutefish-compositor` (файлы `src/render/glass.h`, `src/render/shaders/glass_fragment_shader.glsl`, `src/shell/dock/dock_window.cpp`) показало:
- Разработчики CutefishOS прямо зафиксировали архитектурный принцип: `specularIntensity = 0.0f` (зеркальные блики вызывают ощущение пластика), `sheen = 0.0f` (направленное вертикальное осветление вызывает белесую дымку), `ambientOcclusion = 0.0f`.
- Под Доком полностью отсутствует drop shadow (тень). Контейнер лежит непосредственно над фоном рабочего стола.
- Окантовка представляет собой чистый равномерный 1px hairline кант без угловых вспышек.

## Decision

1. **Удаление внешней тени Дока:**
   - В `crates/rusty-compositor/src/shell_render/mod.rs` (`push_dock_chrome_shapes`) полностью удален вызов `push_soft_shadow(out, shape_cache, renderer, capsule, DOCK_RADIUS, 20, 72)`.
2. **Очистка шейдера Liquid Glass (`LIQUID_GLASS_FRAG`):**
   - Устранены угловые вспышки и внутренний каустик для Дока: вычисление `spec_dir` для Дока зафиксировано на `1.0` (чистый равномерный 1px hairline кант по всей границе `outer_bevel`), а для всплывающих окон сохранено деликатное направленное сопряжение через `smoothstep(0.01, 0.05, u_sat_refract.w)`.
   - В `compute_glass_material` занулен `sheen = 0.0` для `GlassPanelStyle::Dock` в светлой и темной темах (`sat_refract_rim_sheen: [..., 0.0]`), а вес равномерного канта установлен в `0.26` (Light) и `0.18` (Dark).
3. **Синхронизация SDF-сэмплера (`sdf.rs`):**
   - Для `GlassPanelStyle::Dock` обнулен `sheen_limit = 0.0`, а угловой фактор заменен на постоянный `1.0` для формирования симметричной 1px окантовки по всем 4 сторонам.
4. **Тесты и верификация:**
   - Обновлен тест `dock_glass_and_icon_shadow_rasterize_cleanly`: подтверждена полная симметрия и равномерность 1px канта по углам (`top_left_arc[3] == top_right_arc[3]`, `bottom_left_arc[3] == bottom_right_arc[3]`).
   - Все 250 unit-тестов воркспейса успешно пройдены, 0 clippy warnings.
   - Выполнен живой `--winit` запуск на дисплее `:1` и визуальная проверка в скриншот-монтаже.

## Consequences

- Док полностью соответствует эстетике CutefishOS: плоское матовое стекло, чистый тонкий 1px кант без пластиковых угловых бликов, полное отсутствие паразитной тени под доком.
