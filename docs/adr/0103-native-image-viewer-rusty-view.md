# ADR-0103: Нативный просмотрщик изображений `rusty-view` (`apps/rusty-view`)

- **Status:** Accepted
- **Date:** 2026-11-24
- **Task:** `RUSTYOS-174`
- **Decisions Log:** `D-117`

## Context

В RustyOS до настоящего момента отсутствовал встроенный графический просмотрщик растровых изображений (PNG, BMP, PPM/PNM). Пользователю требовался просмотрщик графики с нативным UI RustyOS в стиле Liquid Glass, высокой скоростью запуска, отсутствием лишних декораций, интерактивным зумом и панорамированием, переключением изображений в текущей папке и полной интеграцией с файловым менеджером `rusty-files` и MIME-системой.

## Decision

Создать нативное графическое приложение `apps/rusty-view` (`rusty-view`) на базе крейтов `rusty-ui`, `rusty-services` и `smithay-client-toolkit` (`0.19.2`) со следующими характеристиками:

1. **Zero-Chrome Viewport:** Окно открывается без громоздких панелей инструментов сверху; 100% полезной площади отдано изображению с центрированием на нейтральном холсте (`#101114` / `#EEF0F5`) и стандартными CSD светофорами управления окном.
2. **Парящий тулбар Liquid Glass:** Внизу окна по центру отображается плавающая полупрозрачная капсула (`330x42 px`, скругление `21 px`, размытие/матовость `Liquid Glass`, автоскрытие через 2.5 сек отсутствия движения мыши) с кнопками «Назад», «Зум -», «100%», «Зум +», «По размеру окна», «Поворот на 90° по часовой», «Инфо» и «Вперёд».
3. **Навигация и плейлист:** Автоматическое сканирование каталога открытого файла, сортировка по имени, циклическое переключение колесом мыши или стрелками влево/вправо/пробелом.
4. **Интерактивный зум и панорамирование:** Масштабирование колесом мыши с фиксацией точки под курсором (`10%..=2500%`), панорамирование зажатием левой кнопки мыши на холсте, возврат к 100% клавишей `0`, подгонка под размер окна клавишей `9` или `F`.
5. **Безопасные кодеки (100% Safe Rust, 0 new dependencies):** Расширение `crates/rusty-services/src/image_decode.rs` декодером BMP (24-bit RGB, 32-bit RGBA, 8-bit paletted) и диспетчером `decode_image_rgba_limited` (PNG, BMP, PPM).
6. **Системная интеграция:** Файл `packaging/applications/org.rustyos.view.desktop` и регистрация по умолчанию для MIME-типов `image/png`, `image/bmp`, `image/x-bmp`, `image/x-portable-pixmap`, `image/x-portable-anymap` в `rustyos-mimeapps.list`.

## Consequences

- 0 новых зависимостей в `Cargo.lock` и 0 `unsafe`.
- Полная независимость от внешних сторонних утилит и сред.
- Высокая отзывчивость и чистый пользовательский интерфейс в эстетике RustyOS.
