# ADR-0042: Унифицированное системное контекстное меню по стандарту macOS 27 и декомпозиция подсистемы меню

- **Статус:** accepted
- **Дата:** 2026-11-17
- **Задача:** `RUSTYOS-086`
- **Связанные решения:** `D-050`, `D-038`, `D-032`, `ADR-0027`, `ADR-0032`

## Контекст

1. **Архитектурный долг и перегрузка файлов:**
   Аудит кодовой базы выявил избыточный размер файла `crates/rusty-compositor/src/state/context_menu_actions.rs` (1647 строк), который совмещал разнородные зоны ответственности: логику сканирования и упорядочивания файлов Рабочего стола, парсинг стека Загрузок, запуск фонового воркера Корзины, управление автозапуском Dock-приложений, завершение процессов (`SIGKILL`) и построение меню.

2. **Несогласованность контекстных меню по правой кнопке мыши:**
   - Правый клик по заголовку (SSD titlebar) или рамке окна игнорировался либо проваливался без действия.
   - Запросы клиентских декораций CSD (`xdg_toplevel.show_window_menu` в Wayland) обрабатывались пустой заглушкой.
   - Различные приложения имели изолированные меню без единой системной базы управления окном.

3. **Анализ стандарта macOS 27 Golden Gate:**
   - В macOS правый клик по заголовку окна или удержание/клик по зеленой кнопке открывает системное меню управления окном: тайлинг (Move & Resize / Tile to Left / Right), Zoom, перенос на другой монитор (Move to Display), перенос на рабочие столы (Spaces / Desktops), Minimize и Close/Force Quit.
   - Клиентские контекстные меню приложений строятся по гибридному принципу: сверху отображаются контекстные действия самого приложения, а снизу (через разделитель) — системные оконные действия.

## Решение

1. **Модульная декомпозиция подсистемы контекстных меню (`crates/rusty-compositor/src/context_menu/`):**
   - `window_menu.rs`: построение нативных системных оконных меню (`build_window_context_entries`, `build_minimized_window_context_entries`);
   - `desktop_menu.rs`: сканирование канваса Рабочего стола, сетка иконок, создание папок, переименование, перемещение в корзину;
   - `dock_menu.rs`: меню приложений Dock, стек и веер Загрузок, управление Корзиной и фоновые каналы очистки;
   - `actions.rs`: исполнитель действий `execute_context_menu_action`, управление процессами, динамическое переключение `Alt` (`Quit` <-> `Force Quit`);
   - `mod.rs`: центральный координатор, хит-тесты, обработка кликов, ховеров и навигации с клавиатуры;
   - `crates/rusty-compositor/src/state/context_menu_actions.rs`: сохранён как легковесный фасад обратной совместимости, реэкспортирующий `crate::context_menu::*`.

2. **Системное меню управления окном (`ContextMenuTarget::Window(WindowId)`):**
   - Добавлены новые действия в `ContextMenuAction`: `WindowTileLeft`, `WindowTileRight`, `WindowToggleMaximize`, `WindowMoveToNextOutput`.
   - Поддерживается вызов:
     - Правым кликом по SSD-заголовку и рамке окна;
     - Комбинацией `Alt + Правый клик` или `Super + Правый клик` по любой области окна (SSD и CSD);
     - Протокольным запросом Wayland `xdg_toplevel.show_window_menu`.
   - Состав меню:
     - *Tile Window to Left* (`⌥←`)
     - *Tile Window to Right* (`⌥→`)
     - *Zoom* / *Restore Size* (`⌥F`)
     - *— разделитель —*
     - *Move to Desktop* (подменю с перечнем рабочих столов `1..9` и отметкой текущего)
     - *Move to Next Display* (`⌥O`, если доступно более одного дисплея)
     - *— разделитель —*
     - *Minimize* (`⌘M`)
     - *Close* (`⌘W`) / при удержании `Alt`: *Force Quit* (с подсветкой опасного действия).

3. **Интеграция гибридного меню в `apps/rusty-files`:**
   - Правый клик по панели инструментов и пустому пространству заголовка транслируется композитору через `show_window_menu`.
   - Контекстное меню канваса файлов дополнено стандартными системными пунктами (*Zoom*, *Minimize*, *Close Window*) под разделителем.

## Последствия

- Ликвидирован монолитный файл на 1600+ строк: каждый подмодуль меню сфокусирован и не превышает 400–700 строк.
- Обеспечен единообразный UX управления окнами по стандарту macOS 27 Golden Gate для всех приложений в сессии (как с серверными, так и с клиентскими декорациями).
- Сохранена полная бинарная и исходная совместимость внутренних API композитора.
