# ADR-0049: macOS 27 Pill Capsule Liquid Glass Dock Container

## Status

accepted

## Context

В ходе визуального аудита и живой сверки с референсными снимками macOS 27 Golden Gate (`docs/design/references/macos-27-golden-gate/`) было выявлено визуальное расхождение между рендерингом Дока RustyOS и эталоном macOS 27:
1. Контейнер Дока в RustyOS имел скругление углов `DOCK_RADIUS = 22` при высоте `DOCK_HEIGHT = 68`, что оставляло 24px плоской вертикальной стенки на боковинах (скруглённый прямоугольник вместо капсулы). В эталоне Док — это идеальная непрерывная вытянутая капсула (`pill capsule`, `radius = height / 2 = 34px`).
2. Оптический фасет блика рассчитывался по формуле `spec_dir = d_tl^7 + d_br^7 * 0.62`. Из-за возведения в 7-ю степень на строго горизонтальной верхней кромке блик угасал почти до нуля (`0.707^7 ≈ 0.088`), а вокруг всего контейнера рисовался бледный 1px контур без ощущения толщи физического стекла. В эталоне свет падает сверху (`top-lit`), формируя непрерывный яркий световой шельф по всей верхней кромке с плавным огибанием торцов и тёмным контактным притенением снизу.
3. Под капсулой Дока в RustyOS отсутствовала пространственная тень (`push_soft_shadow`), из-за чего Док казался «приклеенной» плоской наклейкой. В эталоне под Доком лежит мягкая рассеянная тень (spread: 20px, max_alpha: 72), обеспечивающая эффект парения в 3D-пространстве.

## Decision

1. **Pill Capsule геометрия:**
   - Зафиксировать `DOCK_RADIUS = DOCK_HEIGHT / 2` (34px) в `crates/rusty-compositor/src/shell_render/tokens.rs` и `apps/rusty-shell/src/wayland.rs`.
   - Ввести `DOCK_CAP_PADDING = 14px` на концах капсулы, чтобы крайние иконки располагались в зоне прямого участка и не накладывались на кривизну полукругов.
2. **Top-Lit Glass Shelf Highlight & Ambient Shading:**
   - В шейдере `LIQUID_GLASS_FRAG` и аналитическом CPU-семплере `sdf.rs` внедрить верхнее освещение `light_top = vec2(-0.35, -0.94)` и расчет `top_shelf = top_light^2 * (0.5 + 0.5 * top_light)`.
   - Скомбинировать шельф с угловыми бликами: `spec_dir = (arc_tl + arc_br * 0.62) * 0.35 + top_shelf * 0.75`.
   - Добавить контактное притенение нижней грани `shadow_edge = outer_bevel * max(grad.y, 0.0) * (1.0 - is_light * 0.45)`, убирающее паразитную нижнюю полосу и придающее стеклу физическую толщину.
3. **Объемная тень:**
   - В `push_dock_chrome_shapes` подключить вызов `push_soft_shadow(out, shape_cache, renderer, capsule, DOCK_RADIUS, 20, 72)` сразу под стеклянным контейнером в строгом front-to-back Z-порядке.
4. **Тесты:**
   - Обновить константные проверки в `macos_dock_divider_gap_tooltip_and_radii_constants` до `DOCK_RADIUS = 34`.
   - Сохранить 100% прохождение всех 250 тестов воркспейса.

## Consequences

- Контейнер Дока визуально неотличим от эталона macOS 27 Golden Gate (Pill Capsule, выразительный верхний стеклянный шельф, мягкое парение над обоями).
- Полная обратная совместимость всех публичных контрактов и внутренних алгоритмов компоновки.
- 0 предупреждений Clippy, чистый `cargo fmt`.
