# Hardware Compatibility

- Use HARDWARE.md and docs/HARDWARE_MATRIX.md.
- Test exact device/driver/kernel combinations.
- Distinguish tested support from theoretical capability.
- Verify fallback when optional features are missing.
- Test multi-monitor, mixed refresh, hotplug and suspend/resume.
- Never change installed drivers or system config without approval.
