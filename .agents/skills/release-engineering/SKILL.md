# Release Engineering

- Keep builds reproducible and record toolchain/dependency versions.
- Separate dev builds from release artifacts.
- Verify checksums/signatures where applicable.
- Include known issues and tested hardware matrix.
- Never publish or deploy releases without user approval.
- Include rollback/recovery guidance for installers and updates.
