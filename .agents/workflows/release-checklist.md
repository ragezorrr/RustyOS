# Release Checklist Workflow

1.  Confirm release scope and obtain user approval.
2.  Check Git state and version.
3.  Run formatting, lint, tests and reproducible build checks.
4.  Review dependency/security changes.
5.  Verify packaging and recovery instructions.
6.  Verify hardware claims against the actual matrix.
7.  Prepare release notes, known issues and checksums.
8.  Do not publish, sign or deploy without explicit approval.
