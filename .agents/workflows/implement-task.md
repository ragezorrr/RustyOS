# Implement Task Workflow

1.  Confirm task is approved and in scope.
2.  Inspect Git status; preserve unrelated user changes.
3.  Read relevant code and one relevant skill.
4.  Implement the smallest complete change.
5.  Run targeted checks, then broader checks if warranted.
6.  Inspect diff for accidental changes.
7.  Update task/documentation status.
8.  Report files changed, tests run, results and limitations.
