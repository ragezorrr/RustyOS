# Project Bootstrap Workflow

1.  Read `AGENTS.md`, `ROADMAP.md`, `ARCHITECTURE.md` and `TASKS.md`.
2.  Inspect workspace and environment using read-only, targeted
    commands.
3.  Do not install packages or modify host configuration.
4.  Propose exact files, commands, acceptance checks and risks.
5.  Wait for user approval before making changes.
6.  After approval, implement only RUSTYOS-001.
7.  Run fmt, check, clippy and tests.
8.  Inspect diff and report concise results.
